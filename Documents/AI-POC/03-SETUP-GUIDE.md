## Prerequisites

Before setting up the project, ensure the following are installed on your development machine:

| Requirement | Minimum Version | Check Command |
|---|---|---|
| Node.js | 18.17 | `node --version` |
| npm | 9.0 | `npm --version` |
| Git | 2.0 | `git --version` |

**Supported operating systems:** Windows 10/11, macOS 12+, Ubuntu 20.04+

**Note:** FFmpeg is **not** required as a system-level dependency. The project includes `@ffmpeg-installer/ffmpeg`, which bundles a prebuilt FFmpeg binary that works across all supported platforms.

## Step 1 — Clone the Repository

```bash
git clone <repository-url>
cd ai-checker
```

Replace `<repository-url>` with the actual Git remote URL provided by your team lead.

---

## Step 2 — Install Dependencies

```bash
npm install
```

This installs all runtime and development dependencies, including:

- Next.js 16 and React 19 (framework)
- Axios, Zod (HTTP + validation)
- react-dropzone (file upload UI)
- fluent-ffmpeg + @ffmpeg-installer/ffmpeg (video frame extraction)
- recharts (charting library for video per-frame timeline)
- framer-motion (animations)
- Tailwind CSS (styling)

Expected install time: 30–90 seconds depending on network speed.

If you encounter permission errors on macOS/Linux, do **not** use `sudo`. Instead, fix npm permissions: https://docs.npmjs.com/resolving-eacces-permissions-errors-when-installing-packages-globally

## Step 3 — Obtain API Keys

You need free-tier API keys from two providers. Both require only an email address — no credit card.

### 3.1 Sapling (Text Detection)

1. Navigate to https://sapling.ai
2. Click **Sign Up** and create an account with your email
3. After email verification, log in to the dashboard
4. Navigate to **API Key** section (or **Dashboard → Settings**)
5. Click **Generate Key**
6. Copy the API key (a 32-character alphanumeric string)

**Free tier limit:** 50,000 characters per 24-hour rolling window.

### 3.2 Sightengine (Image & Video Detection)

1. Navigate to https://sightengine.com
2. Click **Sign Up** and create a free account
3. After email verification, log in to the dashboard
4. Your **API User** and **API Secret** are displayed on the dashboard home page (or under **API Settings**)
5. Copy both values

**Free tier limit:** 2,000 operations per month (approximately 500/day soft cap).

### 3.3 Optional Providers

| Provider | Status | Notes |
|---|---|---|
| GPTZero | Paid subscription required (as of July 2026) | Leave `GPTZERO_API_KEY` blank unless you have a paid plan |
| AI or Not | No confirmed public API | Leave `AIORNOT_API_KEY` blank — the provider is stubbed |

## Step 4 — Configure Environment Variables

### 4.1 Create the Local Environment File

```bash
cp .env.example .env.local
```

### 4.2 Add Your API Keys

Open `.env.local` in your editor and fill in the values:

```bash
# Text detection — Sapling (primary)
SAPLING_API_KEY=your_sapling_api_key_here

# Image/Video detection — Sightengine (primary)
SIGHTENGINE_API_USER=your_sightengine_api_user_here
SIGHTENGINE_API_SECRET=your_sightengine_api_secret_here

# Optional — leave blank if not available
GPTZERO_API_KEY=
AIORNOT_API_KEY=
```

### 4.3 Security Notes

- `.env.local` is listed in `.gitignore` and will **never** be committed to version control
- API keys are read server-side only via `process.env` — they are never bundled into the client JavaScript
- Do not share `.env.local` via Slack, email, or any unencrypted channel
- If a key is compromised, regenerate it immediately from the provider's dashboard

## Step 6 — Verify the Setup

Open http://localhost:3000 in your browser. You should see the AI-Checker page with three tabs: Text, Image, and Video.

### 6.1 Verify Text Detection

1. Select the **Text** tab
2. Paste the following test text (generated by ChatGPT):

```
Artificial intelligence has fundamentally transformed the landscape of modern technology, enabling unprecedented capabilities in natural language processing, computer vision, and autonomous decision-making systems that continue to evolve at a remarkable pace.
```

3. Click **Check Text**
4. You should see a result card with a percentage, verdict, and "via sapling" attribution
5. If you see an error toast saying "Detection is temporarily unavailable," your Sapling API key may be incorrect

### 6.2 Verify Image Detection

1. Select the **Image** tab
2. Upload any JPG or PNG photograph from your device
3. Click **Check Image**
4. You should see a result card with a percentage, verdict, and "via sightengine" attribution
5. A real photograph should return a low percentage ("Likely Human")

### 6.3 Verify Video Detection (optional)

1. Select the **Video** tab
2. Upload a short MP4 file (under 20MB)
3. Click **Check Video**
4. After processing (10–30 seconds), you should see a result card plus a per-frame timeline chart

## Troubleshooting

### "Module not found" errors after cloning

```bash
rm -rf node_modules package-lock.json
npm install
```

### Port 3000 already in use

```bash
# Find and kill the process using port 3000
# macOS/Linux:
lsof -ti:3000 | xargs kill -9

# Windows (PowerShell):
Get-Process -Id (Get-NetTCPConnection -LocalPort 3000).OwningProcess | Stop-Process -Force
```

Then restart with `npm run dev`.

### FFmpeg errors during video processing

The bundled FFmpeg binary from `@ffmpeg-installer/ffmpeg` should work without system-level installation. If you encounter errors:

1. Delete `node_modules` and reinstall: `rm -rf node_modules && npm install`
2. Ensure `next.config.ts` includes `serverExternalPackages: ["fluent-ffmpeg", "@ffmpeg-installer/ffmpeg"]`
3. Confirm the API route has `export const runtime = "nodejs"` (not Edge runtime)

### API key errors (401 / 403)

- Verify the key is correctly pasted in `.env.local` (no leading/trailing whitespace)
- Ensure `.env.local` is in the project root directory (same level as `package.json`)
- Restart the development server after changing `.env.local` — environment variables are loaded at startup

### Provider returning 429 (rate limit)

This is expected behavior when a provider's free tier quota is exhausted. The fallback chain will automatically try the next provider. If all providers are exhausted, wait for the quota to reset (typically 24 hours for Sapling, monthly for Sightengine).

### Dark mode not applying

- The theme system detects the OS-level preference by default
- Use the theme toggle button (top-right corner) to switch manually
- If the theme appears stuck, clear browser cookies for `localhost` and refresh
